# 入门术语表

|术语|直观解释|容易混淆的地方|
|---|---|---|
|VLM|看图并处理语言的模型|能回答图像问题不等于会控制机器人|
|VLA|把视觉、语言与机器人动作联系起来的策略|不保证一定用大语言模型或动作 token|
|Policy / 策略|根据观测和目标选择动作的函数|不是单纯任务描述或聊天回答|
|Behavior Cloning / BC|用示教的观测与动作训练策略模仿专家|离线损失低不等于闭环成功率高|
|Imitation Learning|从演示学习行为的一类方法|BC 是其中一种；不等同强化学习|
|Proprioception / 本体状态|机器人自己的关节、末端等状态|与看外界的相机观测不同|
|Embodiment / 形态|机器人的身体、传感器和动作接口|同样 7 个数字也可能表示不同动作|
|Action Space|模型输出动作的语义、范围和单位|要确认坐标系、绝对/增量、关节/末端|
|Action Chunk|一次预测一段未来动作|预测长度与开环执行长度不同|
|Temporal Ensemble|对不同时间预测到同一步的动作进行融合|不是普通批量平均整个动作序列|
|Tokenization|把连续信息转换成可生成的符号序列|动作 token 与自然语言单词的语义不同|
|Autoregressive|根据已生成部分逐步生成后续 token|长动作块可能增加时延|
|Diffusion Policy|通过迭代去噪生成条件动作序列|动作去噪不等同图像生成，虽共享建模思路|
|Flow Matching|学习噪声与数据之间连续路径上的速度场|与扩散相关，但训练目标和采样方程不能直接混写|
|Action Expert|专门建模机器人动作的子网络|通常要通过注意力或条件机制接入主干信息|
|LoRA|以低秩可训练增量适配大模型|仍需数据、训练和目标机器人动作对齐|
|Fine-tuning|用目标数据进一步训练预训练模型|不是零样本部署|
|Zero-shot|在明确的新任务/环境划分上不使用该目标的额外训练|不是「完全没见过任何相关数据」|
|OOD|超出某个指定训练分布|必须说明改变的是物体、场景、任务还是形态|
|Closed Loop / 闭环|执行过程中反复感知并更新动作|输出动作块也可以滚动闭环执行|
|Control Frequency|每秒更新或执行多少次控制|模型 token 生成速度不是实际控制频率|
|Normalization|把不同尺度的动作转换为便于训练的数值|反归一化用错数据集统计量会导致错误动作|
|RLDS|用于表示强化学习/机器人轨迹的数据格式生态|不是一个控制策略或机器人数据集本身|
|Sim-to-real|从仿真迁移到真实机器人|仿真成功率不能自动当成真机成功率|
|Ablation / 消融|控制其他变量，移除或替换某部分来检验贡献|完整系统比较不一定能归因到一个模块|

## 读生成式动作模型前的最低数学准备

先会看矩阵维度、条件概率、梯度、交叉熵与均方误差。读动作头时能分清观测条件 `o`、任务条件 `l`、动作块 `a`、噪声与生成时间变量 `t` 就足够开始。无需先学完整机器人动力学再读第一篇论文。

行为克隆的直观目标是让策略在演示观测上预测演示动作。连续单峰预测常用回归，离散动作 token 常用交叉熵，多峰连续动作可以用生成式模型。具体论文使用哪个损失、如何加权、是否冻结主干，都要回到原文确认。
