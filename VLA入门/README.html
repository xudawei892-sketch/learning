VLA 入门资料包

从零开始，先理解机器人怎样把「看见、听懂」变成「能执行的动作」，再读主线论文，最后进入仿真。

当前状态：32 篇原始 PDF 已全部取得，中文导读、编年史、领域地图与阅读计划已建立。 每篇目录都有 paper.pdf、笔记.md 和原文首页摘录。笔记已核对原文标题、摘要/首页，定位为入门导读，尚未逐页精读所有论文。详细状态见 下载状态。

从哪里开始

  1. 花 30 分钟读 快速入门与编年史，理解几条研究路线。
  2. 对照 领域地图、术语表 和 核心模型对照，先弄清输入、动作表示、数据和评测。
  3. 按 三周阅读计划 阅读；不要顺序硬啃所有 32 篇。
  4. 到 论文目录 打开某篇的中文导读，再对照原文阅读；用 阅读进度.csv 记录自己的问题。
  5. 学完核心论文后，参考 仿真路线 选择一个最小实验。

获取原始 PDF

本轮初次访问曾受网络策略拦截，加入 arxiv.org 和 export.arxiv.org 的配置草稿后，后续实际请求成功，32 篇 PDF 均已取得。31 篇来自 arXiv，ALOHA Unleashed 来自作者项目的官方 PDF。草稿已保存，但本轮未发布环境配置；后续新环境的访问能力需要在发布后验证。

在仓库目录执行：

cd /workspace/learning
python3 VLA入门/tools/download_papers.py --probe
python3 VLA入门/tools/download_papers.py --workers 3

只下某一篇：python3 VLA入门/tools/download_papers.py --only 2406.09246。网络不通时先 probe，不要重复批量发送注定失败的请求。下载器保留 TLS 验证，检查 PDF 文件头和结尾、长度并记录 SHA-256。哈希用于后续完整性检查，不是作者签名认证。默认使用来源当前提供的版本，记录实际响应 URL 与下载时间；本轮另从 PDF 提取版本标识和页数写入清单。未指定固定 v1，也不声称未来重新下载必然得到同一个版本。

本轮不批量下载 LaTeX 源码、权重和训练数据，也不启动仿真；你本轮要求的是入门文献资料。代码入口已记录，官方 README 快照已保存，完整源码仓库没有克隆。

范围与证据

收录范围是 2020–2025 的代表性主线及背景资料，其中一些是数据/评测论文、一些是语言规划或视觉策略，并非全部都是现代端到端 VLA。它是新手阅读起点，不是截至 2026 年 10 月的完整最新综述，也不是按引用量评出的 32 篇经典排名。

每篇都给出动机、方法、贡献、边界、精读问题和前置知识。尚未核验的指标、公式与图号不写成事实。官方项目 README 只是辅助证据，可能比论文更新；来源与核验范围见 资料来源。原文已下载并核对标题、摘要/首页与版本标识；后续精读方法和实验，再将对应笔记升级为精读笔记。
